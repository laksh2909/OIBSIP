# Velora Coffee — Landing Page

## About the Project
Velora Coffee is a responsive landing page for a fictional premium coffee brand. It features a warm, coffee-inspired design and a simple, user-friendly layout.

## Features
- Sticky navigation with section links
- Hero section with a call-to-action button
- Three feature cards
- Brand story section and footer
- Responsive layout for mobile and desktop screens
- Smooth scrolling between sections

## Technologies Used
- HTML5
- CSS3
- Flexbox and CSS Grid
- Media queries for responsive design
